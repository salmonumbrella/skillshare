# レシピ

> よくある skillshare のシナリオに対するコピー&ペースト可能な解決策。

各レシピは同じ構造に従います。**シナリオ**（いつ・なぜ）、**解決策**（手順）、**確認**（確かめ方）、
**バリエーション**（代替案）。

## 利用可能なレシピ

| レシピ | シナリオ |
|--------|----------|
| [CI/CD Skill 検証](ci-cd-skill-validation) | GitHub Actions / GitLab CI での監査 + sync |
| [プライベートエンタープライズ Skill](private-enterprise-skills) | トークン認証によるプライベートリポジトリのインストール |
| [Project Mode ワークフロー](skill-per-project-workflow) | プロジェクトスコープの Skill ライフサイクル全体 |
| [クロスマシン Sync](cross-machine-sync-recipe) | マシン間で Skill を push/pull する |
| [チームオンボーディング](team-onboarding-recipe) | 新入社員の Skill 環境セットアップ |
| [集中管理された Skill リポジトリ](centralized-skills-repo) | Skill は1つのリポジトリ、Target は各開発者の config で |
| [多数の Project を 1 つの Config で](many-projects-one-config) | global config から複数の project フォルダーに Skill と MCP サーバーを配布する |
