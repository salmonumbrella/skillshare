# Recipes

> 針對常見 skillshare 情境的複製貼上解決方案。

每個 recipe 都遵循相同結構：**情境**（何時／為何）、**解決方案**（逐步操作）、**驗證**（如何確認）、**變化**（其他做法）。

## 可用的 Recipes

| Recipe | 情境 |
|--------|----------|
| [CI/CD Skill 驗證](ci-cd-skill-validation) | 在 GitHub Actions / GitLab CI 中執行 audit + sync |
| [私有企業 Skills](private-enterprise-skills) | 使用 token 認證安裝私有 repo |
| [Project Mode 工作流程](skill-per-project-workflow) | 完整的 Project 範圍 Skill 生命週期 |
| [跨機器同步](cross-machine-sync-recipe) | 跨機器 push/pull Skills |
| [團隊導入](team-onboarding-recipe) | 新進人員的 Skill 環境設定 |
| [集中式 Skills Repo](centralized-skills-repo) | 一個 repo 存放 Skills，Targets 存在每位開發者的 config 中 |
| [多個 Projects，一份 Config](many-projects-one-config) | 從 global config 把 Skills 與 MCP servers 送進多個 project 資料夾 |
