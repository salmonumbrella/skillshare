# Recipes

> 자주 있는 skillshare 시나리오를 위한 복사-붙여넣기 해결책입니다.

각 recipe는 동일한 구조를 따릅니다: **Scenario**(언제/왜), **Solution**(단계별 방법),
**Verification**(확인 방법), **Variations**(대안).

## 사용 가능한 Recipe

| Recipe | 시나리오 |
|--------|----------|
| [CI/CD Skill Validation](ci-cd-skill-validation) | GitHub Actions / GitLab CI에서 감사 + 동기화 |
| [Private Enterprise Skills](private-enterprise-skills) | 토큰 인증을 사용한 비공개 저장소 설치 |
| [Project Mode Workflow](skill-per-project-workflow) | 완전한 프로젝트 범위 Skill 라이프사이클 |
| [Cross-Machine Sync](cross-machine-sync-recipe) | 여러 기기 간 Skill push/pull |
| [Team Onboarding](team-onboarding-recipe) | 신규 입사자 Skill 환경 설정 |
| [Centralized Skills Repo](centralized-skills-repo) | Skill은 하나의 저장소에, Target은 각 개발자의 설정에 |
| [Many Projects, One Config](many-projects-one-config) | global 설정에서 여러 프로젝트 폴더로 Skill과 MCP 서버 보내기 |
